Information

1. Introduction

This app is a web-based, integrated Bible study app that lets you view multiple Bible texts and Bible concordances side by side, in parallel, by version.

2. Panel

A panel is a single window that displays Bible text, a concordance, notes, and more.

2.1 Add Panel

Adds a new panel to the right of the existing panels.

2.2 Panel View

Sets how many panels are visible on screen at once.

Sets the panel's width to match the full width of the screen, so only one panel is shown.

Shows however many panels are set in the number selector on screen at once.

2.3 Font Size

Adjusts the font size of the Bible text shown in the panel.

2.4 Panel Linking

Multiple panels show the same Bible passage, with scrolling linked so the same verse lines up in every panel.

Links with an existing panel, or with a newly added panel.

Hides every linked panel except one.

Shows the linked panels that were hidden.

2.5 Reading Mode

Displays the Bible text as continuous prose, without chapter/verse breaks.

Enabled only when a single panel is open with a single version selected.

Adds chapter/verse numbers to the text in reading mode.

3. Bible Versions

3.1 Add Version

Adds a version icon to the top of the panel for whichever version you want to view.

3.2 Reorder Versions

Grab a version icon's handle at the top of the panel and drag it to change the order of the versions.

3.3 Version Highlight / Mute

Click a version icon at the top of the panel to highlight or mute that version's text.

4. Bible Concordance

4.1 Keyword Search

See where a keyword you enter appears throughout the Bible, in the versions selected.

4.2 Hebrew / Greek Concordance

Strong's Concordance: every Hebrew or Greek word in the Bible has a numeric code -- Hebrew 1-8674, Greek 1-5624 -- with an explanation of its meaning.

Englishman's Concordance: shows how that word is used elsewhere in the Bible.

Click a Hebrew or Greek word block to see its concordance entry.

4.3 Cross References

The Treasury of Scripture Knowledge is a cross-reference commentary compiled by Rev. R. A. Torrey.

For a verse in the KJV Bible, shows the Bible verses associated with each word and phrase, in the versions selected.

5. Verse Options

5.1 Verse Selection

Select Range: selects every verse between the first verse clicked and the second verse clicked.

Select Individually: selects only the verses clicked, one at a time.

5.2 Copy

Copies the selected verses, by the selected versions.

5.3 Go to Verse

From a list of Bible verses in search results or a concordance, opens that verse in a panel.

Opens the verse in an existing panel, or in a newly added panel.

5.4 Highlight

Highlights the selected version's Bible verse. Click it to change the highlight color or remove it.

5.5 Bookmark

Bookmarks the selected verse. Click the bookmark icon to remove it.

5.6 Note

Leaves a note on the selected verse. Click it to view, edit, or delete the note.
